# Scoring Rubric Reference — Adobe Round 3

1. **Detection Accuracy**: Correctly identifies real problems (evidence-backed) across discoverability and engagement, with few misses and few false positives.
2. **Suggested-Action Quality**: Fixes are correctly targeted, mechanism-sound, and prioritized; beyond-problem suggestions are relevant and non-obvious.
3. **Output Design**: Clear, structured, actionable report (evidence + severity + prioritized actions) a non-expert could act on.
4. **Skill-Format & Engineering Hygiene**: Each skill folder is agentskills.io compliant; marketplace manifest is well-formed with exactly one entrypoint; deterministic; safe.
5. **Marketplace Composition**: Genuine separation of concerns with clean composition by entrypoint — not padding.
6. **Generalization**: Works on unseen sites; tested by construction.
